# P7 – Student and course registration

## Run
- Windows: double-click `run.bat`.
- Ubuntu: `chmod +x run.sh && ./run.sh`.

The first run needs internet to install Django. Keep this folder intact.

## Demonstration
1. Add a course.
2. Register a student and select one or more courses.
3. Return Home and select 'View registered students' for a course.
4. Explain the ManyToManyField relationship.

Open: http://127.0.0.1:8000/
