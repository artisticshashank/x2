# Experiment 3 – Current Date and Time

From this folder run `./run.sh` on Ubuntu or `run.bat` on Windows. The launcher creates a local virtual environment and installs the pinned Django dependency.

Open http://127.0.0.1:8000/ to display the server date and time.

The view, template, and URL follow Experiment 3 of the lab manual. The template is referenced as `datetimeapp/current_datetime.html` so Django's app-template loader can find the file inside the app-named templates directory.
