# P3 – Display current date and time

## Run
- Windows: double-click `run.bat`.
- Ubuntu: `chmod +x run.sh && ./run.sh`.

The first run needs internet to install Django. Keep this folder intact.

## Demonstration
1. Start the server using the launcher.
2. Show the current server date and time in the browser.
3. Explain that `datetime.now()` reads the server's current date and time.

Open: http://127.0.0.1:8000/
