# P8 – Register models in Django admin

## Run
- Windows: double-click `run.bat`.
- Ubuntu: `chmod +x run.sh && ./run.sh`.

The first run needs internet to install Django. Keep this folder intact.

## Demonstration
1. Run `python manage.py createsuperuser` in the activated environment.
2. Sign in at `/admin/`.
3. Add Course and Student records using the admin forms.
4. Show StudentAdmin's horizontal course selector and list columns.

Open: http://127.0.0.1:8000/admin/
